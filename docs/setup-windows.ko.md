# Windows 설치 안내

## 요구 사항

- Windows 10 이상.
- 소스 실행용 Python 3.12 또는 호환 가능한 Python 3.
- Xbox 360 컨트롤러 출력에는 `vgamepad` / ViGEm 호환 환경이 필요합니다.

일부 게임이나 관리자 권한으로 실행된 앱에서는 KeyMouse2Pad도 관리자 권한으로
실행해야 입력 캡처가 안정적으로 동작할 수 있습니다.

## 소스에서 실행

```bat
run_gui.bat
```

매핑 설정 저장 위치:

```text
%LOCALAPPDATA%\KeyMouse2Pad\profile.json
```

## exe 빌드

```bat
build_exe.bat
```

결과 파일:

```text
dist\KeyMouse2Pad.exe
```

## 기본 조작

- `F8`: 컨버터 실행/정지 전환.
- `F9`: 독점 패드 모드 전환.

독점 패드 모드에서는 매핑된 키보드/마우스 입력을 게임패드 출력으로 변환하고,
원래 키보드/마우스 이벤트가 포커스된 앱으로 전달되지 않도록 차단합니다.

## 문제 해결

- 컨트롤러 출력이 안 되면 GUI 상태 표시를 먼저 확인하세요.
- 게임에서 입력 캡처가 안 되면 관리자 권한으로 실행해 보세요.
- 매핑이 맞지 않으면 GUI의 매핑 항목에서 원하는 키로 수정한 뒤 저장하세요.
