# Security Policy

KeyMouse2Pad works with system-wide input capture and controller emulation, so
security reports are welcome even when the issue looks small.

## Reporting

Please do not open a public issue for a security-sensitive problem. Report it to
the repository owner through GitHub private contact options or by email if one is
listed on the maintainer profile.

Include:

- A short impact summary.
- Reproduction steps.
- Affected commit or release.
- Whether administrator privileges are required.

## Scope

In scope:

- Input capture behavior that leaks or records data unexpectedly.
- Privilege boundary issues.
- Unsafe driver or installer behavior.
- Release artifact tampering concerns.

Out of scope:

- General anti-cheat compatibility.
- Games blocking virtual controllers.
- Requests to bypass platform or game security systems.
